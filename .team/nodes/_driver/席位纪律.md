## 一、量具（🔴 本仓库栽最多的地方）

**先怀疑量具，再怀疑被测物。「没报错」不等于「工作正常」。**

| 坏量具 | 实撞症状 | 正确做法 |
|---|---|---|
| `cmd \| tail` 取 `$?` | 构建失败读成 rc=0 | ⛔ 退出码不许经管道，先落文件再读 |
| grep 源码标识符判包版本 | 恒假阴性（资源在 .app 里压缩存） | 比对 `dist/assets/*` 文件名 |
| tmux pane 里起 GUI 截图 | 全白（AX windowCount=0） | 同命令先截一个**已知有内容**的窗口做阳性对照 |
| 只判「抛没抛错」 | load 成功但 canvas 空 | 检查**工作结果**，不只检查错误信号 |

- **两头夹住**：**坏态必须红、好态必须绿**。⛔ 只给「修好之后是绿的」证明不了任何事。
- **验证表面 = 交付面**：桌面壳的能力**必须在 `.app` 上验**。`npm run dev` 绿不算数。
- **状态组合穷举**（布局类）：空/有内容 × 展开/折叠 × 普通/全屏 × 单列/多列。
- **判据四态**：通过(0) / 不通过(1) / **不可判(2)** / 不适用。**编译不过 ≠ 测试红。**
